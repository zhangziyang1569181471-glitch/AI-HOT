# 澳洲政策雷达：行业配置与上线交接

站名和六类导航已经使用者确认：移民政策、州担保与邀请、雇主担保、签证办理、留学与毕业生、行业监管。默认面向行业从业者与申请人，官方政策及州担保优先。报刊保持北京时间每天 08:00、每周一 10:00、每月 1 日 10:30 出刊。

## 编辑判断

优先关注签证规则、年度规划与职业清单、项目开关、EOI/ROI、邀请与配额、费用、材料、英语和资金要求、审理优先级、工作权利，以及代理/院校监管与重要判决。范围较窄但影响明确的变化也应正常评价。

降低招生推广、移民套餐、返佣讲座、获签晒图、个案成功率、无证据的“内部消息”、旧政策重发和重复转载的权重。观点可以进入，但不能写成已经发生的事实。

所有写作和归组步骤都应区分提案、征求意见、公布、通过与实施。保留原文中的签证子类、州别、境内外、新旧申请群体、生效/截止日及过渡条件；不同州、子类、财年和邀请轮次不能只因话题相同而合并。邀请、提名和录取不能写成获签。

## 信源与实际覆盖

本地后台启用 40 个官方入口，覆盖八个州与领地及联邦移民、留学、监管和职业评估机构。官方 API 和新闻列表采集原文与日期，原址更新的政策和登记页使用正文变更监测。每个入口间隔 240 分钟到期，后台排程每 5 分钟检查。详细入口与实测记录见 [官方信源接入清单](official-sources.md)。

模型调用保持关闭，选稿与日报由编辑核实。来源默认展示摘要和原文链接；历史公告和未确认日期的页面不作为当日新闻。已有源配置已同步到本地数据库。

## 塔州州担保试点

公开状态页位于 `/state-nomination/tasmania`，侧栏和手机「我的」均有入口。页面显示已核验轮次、上轮记录、ROI 恢复通知、官方路径与核验时间。后台保存新的原页版本时，状态页提示等待复核并继续展示上一次确认的数据。

登录管理员后，可在 `/preview/state-nomination/tasmania/review` 查阅本轮、上轮、原文和采集版本。11 月 20 日轮次经复核后使用同一条材料发布到精选、11 月 23 日日报和状态页，实际轮次日期单独保留。试点的复核与发布通过本次编辑操作完成，采集队列继续记录官网版本。

## 精选校准

保留原始 T1=60、T1_5=65、T2=76、understandFloor=50、browseFloor=40。移除 AI 示例专用的额外类别门槛，没有凭经验替行业调新数值。七类内容使用原有七行五维权重，已改为政策变化、项目更新、申请指南、数据报告、行业事件、观点、解释；提示词的安全边界、噪声压制和 JSON 契约保留。

`industry/gold.example.jsonl` 的两行是明确标记的虚构格式示例，不是真实政策或校准证据。上线前请标注 100–200 条真实资料的“该选/不该选”，按 [精选校准](selection.md) 运行评测，再确认提示词和门槛。代码测试使用本地假模型，不能证明选稿准确率或真实模型效果。

## 已有部署升级

这是从 AI 示例站切换行业的配置变更，公开类别、主题和 MCP 前缀已改变，公开接口版本升为 `5.0.0`。原有类别订阅地址和 `myhot_*` MCP 工具名不能继续按旧含义使用。新前缀是 `au_policy_radar`，六个类别 key 见 `industry/taxonomy.ts`；客户端应从 `/agent` 或 `/openapi-v1.json` 重新获取入口。

没有数据库迁移，也不会删除现有文章、信源或人工设置。`scripts/seed.ts` 只补新 ID，**不会停用旧 AI 信源**。已有站应先备份，在后台暂停旧源并检查旧公开内容是否需要人工下架；不要直接清库。新行业建议使用独立的全新数据库。接入新的官方来源时，重跑种子补充新 ID，再同步已有 ID 的配置和启用状态。

## 使用者仍需决定

1. 正式域名、托管地点、`SITE_URL`、运营主体、联系邮箱和需公示的备案信息。
2. 使用规则的正式授权范围、责任与投诉安排；实际服务器/CDN/模型/飞书等服务、处理地区、日志与反馈保留期及删除流程。`site/pages/` 已为草案，未经确认不作为正式条款生效。
3. 是否进一步扩展职业评估机构、院校和裁判来源。重点官方入口和当前覆盖范围见信源接入清单。
4. 若未来需要无人值守整理，再确认云端模型服务、预算与日调用上限，以及生产推送时间。当前本地模式只自动采集/提取，模型和对外推送关闭，不使用本地模型；自动化测试仅连接假服务。
5. 真实样本的选稿标注和阈值校准。站名和六类已确认，无需重复确认。

## Vercel 部署

Vercel 通过 `vercel.json` 构建网页和 API。部署前把站点数据库用 `pg_dump` 与
`pg_restore` 迁到空的云端 PostgreSQL，保留文章、信源、待审状态和日报版本。Vercel
需要 `DATABASE_URL`、`ADMIN_PASSWORD`、`SESSION_SECRET` 和
`IMG_PROXY_SIGN_SECRET`。受平台保护的预览可为服务端内部 API 请求启用 Vercel 的
Automation Bypass。正式站设置 `SITE_URL` 为自定义域名。

`radar-collection.yml` 在默认分支每 4 小时运行，也可手动触发。配置 GitHub Actions
密钥 `RADAR_DATABASE_URL`，使采集和预览使用同一数据库。每次执行读出启用的澳洲
官方信源、保存采集日志，并提取新材料正文。模型调用关闭，新材料等待编辑审核。
超时或限流的来源会在本轮结束后补抓一次，手动运行可选择只补抓处于异常状态的信源。

品牌图标采用本站雷达图形，报头已按“澳洲移民留学”重新生成。页脚保留 AIHOT 开源框架署名，它是框架来源而非本站品牌。
