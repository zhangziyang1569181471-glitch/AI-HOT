## 内容与来源

澳洲政策雷达聚合澳洲移民、签证、州担保和留学行业的公开资讯，使用模型生成中文标题、摘要和推荐理由。网页、RSS、公开 API、Agent Markdown 和 MCP 使用同一套公开内容。

默认仅展示摘要和原文链接，原文版权归来源方所有；仅在取得来源明确许可并完成相应配置后才展示或再分发全文。来源方可以通过反馈页提出更正、下架或展示调整请求。

## 政策资讯的使用

摘要可能遗漏条件或翻译有误；政策提案、正式公布与开始实施是不同阶段，邀请、提名、录取与签证获批也不相同。请核对原文的签证子类、州别、适用群体、生效日期及过渡安排。本站资讯不能替代针对个人情况的移民或法律意见，不作获签或审理时限保证。

## 接口使用

RSS、公开 API 和 MCP 为匿名只读入口。请按响应的缓存时间轮询，收到 429 时遵守 Retry-After，避免并发重试。运营者仍需确认商业用途、批量使用、公开转载及再分发的授权安排。
